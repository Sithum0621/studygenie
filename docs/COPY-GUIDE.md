# Language copy guide

App eke language dekak thiyenawa:

- **සිංshish** — Sinhala Unicode letters + English words
- **English** — full English

Files:

- [`lib/copy-singlish.json`](../lib/copy-singlish.json)
- [`lib/copy-english.json`](../lib/copy-english.json)
- Switch UI: `සිංshish` / `English`

## සිංshish rules

- English nouns keep karanna: `Network`, `Connection`, `Home`, `Quiz`, `Notes`, `login`
- Sinhala grammar/verbs Sinhala letters walin: `නැහැ`, `කරන්න`, `පුළුවන්`, `එක`
- Latin Singlish (`eka`, `karanna`) use karanna epa

Good:

- `Network නැහැ. Connection එක නැවත check කරලා try කරන්න.`
- `Quiz එක start කරන්න`
- `Notes save උනා. Revision එකට use කරන්න`

## English rules

- Full sentences. Short and clear.
- Same meaning as the සිංshish line.

Good:

- `No network. Check your connection and try again.`
- `Start quiz`
- `Notes saved. Use them for revision.`
